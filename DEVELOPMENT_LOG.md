# BERTA 0 — DEVELOPMENT LOG

## 2026-08-10

### Initial project stabilization

Проект BERTA 0 был собран в рабочем окружении Debian Linux.

Основная среда:

- Debian
- Python 3.13
- virtualenv
- MariaDB
- GigaChat API

### Исправлено подключение Python-зависимостей

В новом virtualenv отсутствовали необходимые пакеты.

Установлены:

- pymysql
- requests
- python-dotenv
- urllib3

### Исправлено подключение GigaChat OAuth

Возникла ошибка:

    SSLCertVerificationError:
    self-signed certificate in certificate chain

В рабочем окружении для OAuth-запроса было отключено SSL verification.

После этого OAuth-соединение успешно устанавливается.

### SSL warnings

urllib3 выдавал:

    InsecureRequestWarning

Предупреждения были отключены для рабочего терминального интерфейса.

Это НЕ считается окончательным решением безопасности.

В будущем желательно установить корректную цепочку CA-сертификатов и вернуть:

    verify=True

### Function Calling

В проект добавлена/проверена функция:

    get_current_time

Она позволяет BERTA получать текущее время локальной машины без попытки угадать его через LLM.

Подтвержденный результат:

    БЕРТА:
    Сейчас 01:02.

### Исправление execute_function

Во время разработки возникла ошибка Python:

    IndentationError:
    expected an indented block

Ошибка была связана с неправильной вставкой блока:

    if name == "get_current_time":

После исправления проект снова запускается.

### Проверенный запуск

BERTA успешно проходит:

    CORE
    MEMORY
    DATABASE
    LINK
    SELF CHECK

и выходит в интерактивный терминал.

### Function Calling logging

Для диагностики временно использовался вывод:

    [BERTA] -> Вызов инструмента: ...

Это полезно для разработки.

При переходе к production можно сделать logging менее подробным.
