# CHANGELOG

## BERTA 0.3

### Архитектура

- Зафиксирован `berta_agent.py` как главный запускаемый файл.
- `main.py` используется как внутреннее ядро.
- Сохранён фирменный ASCII startup logo.
- Сохранён запуск через проектный `.venv`.

### Голос

- Зафиксирован Piper TTS как голосовой движок.
- Зафиксирована модель `ru_RU-irina-medium`.
- Модель располагается в `~/.berta/voices/`.
- Голосовой интерфейс сохранён без замены TTS.

### Function Calling

- Исправлена последовательность `assistant function call → function result`.
- Результаты инструментов сериализуются как валидный JSON.
- Устранена проблема `HTTP 422` при передаче результатов функций.
- Добавлено ограничение последовательных tool calls для защиты от бесконечных циклов.

### Управление ПК

Добавлены/улучшены специализированные возможности:

- определение рабочего окружения;
- определение установленных приложений;
- адаптивный запуск приложений;
- поиск файлов;
- просмотр директорий;
- открытие путей;
- чтение файлов;
- просмотр процессов;
- завершение процессов;
- фоновые задачи.

### Адаптивный запуск приложений

BERTA больше не должна жёстко предполагать конкретную программу.

Пример:

```text
"запусти блокнот"
        ↓
определение доступных приложений
        ↓
выбор подходящего установленного редактора
        ↓
запуск
```

Это позволяет использовать BERTA в различных Linux desktop environments.

### Интерфейс

- Убрано лишнее пользовательское упоминание конкретного нейросетевого провайдера.
- Используется нейтральное обозначение `CORE` / `локальное интеллектуальное ядро`.
- Сохранён голосовой интерфейс.
- Сохранён адаптивный Web UI.

### Безопасность

- Секреты должны храниться вне исходников.
- `.env` не должен попадать в Git.
- Для репозитория используется `.env.example`.

## Правила совместимости BERTA 0.3

Главный запуск:

```bash
python berta_agent.py
```

Голос:

```text
Piper TTS
ru_RU-irina-medium
```

Модель:

```text
~/.berta/voices/ru_RU-irina-medium.onnx
```

Основное окружение:

```text
.venv
```

Внутреннее ядро:

```text
main.py
```

Эти компоненты считаются частью базовой архитектуры BERTA 0.3.
