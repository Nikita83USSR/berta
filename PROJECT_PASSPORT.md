# BERTA 0 — PROJECT PASSPORT

## 1. Назначение проекта

BERTA 0 — локальный автономный AI-агент для Linux.

Проект предназначен для работы на локальной Linux-машине и взаимодействия пользователя с нейросетевым ядром через терминальный интерфейс.

Основная идея:

- пользователь общается с BERTA на естественном языке;
- BERTA использует GigaChat API как нейросетевое ядро;
- BERTA может обращаться к локальной MariaDB;
- BERTA имеет систему Function Calling;
- BERTA может выполнять системные команды;
- BERTA имеет собственную память изменений;
- BERTA имеет функции чтения и изменения собственного исходного кода;
- проект рассчитан на дальнейшее автономное развитие.

## 6. SSL

В текущем окружении ранее возникала ошибка:

    SSLCertVerificationError:
    self-signed certificate in certificate chain

Для рабочего окружения использовалось отключение SSL verification для запросов GigaChat.

Это технический долг проекта.

При дальнейшей разработке желательно перейти на корректную цепочку доверенных сертификатов.

Также были отключены предупреждения urllib3 об unverified HTTPS.

НЕ считать это полноценным решением безопасности.

## 8. Function Calling

В проекте существует система функций.

Основные элементы:

    tools/functions.py
    tools/function_manager.py
    tools/system.py

В старой реализации функции также находятся в:

    berta_agent.py

Function Calling используется для передачи управления от нейросети локальному Python-коду.

Важный принцип:

LLM не должна сама выполнять системные действия.
Она должна запрашивать соответствующую функцию, а Python выполняет действие локально.

## 9. Системные команды

BERTA умеет работать с системной оболочкой через функцию:

    execute_system_command

Для опасных команд предусмотрена отдельная проверка.

При дальнейшем изменении этой системы необходимо сохранять защиту от опасных операций.

---

## 10. Текущее время

В проекте имеется функция:

    get_current_time

Она возвращает текущее локальное время машины.

Это важно: вопрос пользователя "сколько времени" не должен передаваться обратно как обычный текстовый вопрос модели.

BERTA должна использовать локальную функцию.

## 11. Память

Проект содержит систему памяти.

## 18. Правило дальнейшей разработки

Не переписывать проект целиком без необходимости.

Сохранять работающий код.

Перед изменением архитектуры сначала определить:

- что уже работает;
- что сломано;
- что является legacy;
- какие функции используются;
- какие файлы являются актуальными.

Изменения должны быть минимальными и проверяемыми.

После каждого существенного изменения:

    python -m py_compile ...

и затем запуск проекта.
